## Глобальные ограничения

- **Не трогать палитру.** `--accent:#C6304B`, `--accent-2:#7E2434`, `--bg:#FBF7F4`
  остаются как есть. Второй акцент не вводить.
- **Не трогать SEO-каркас:** `<title>`, `description`, `canonical`, JSON-LD,
  `sitemap.xml`, `robots.txt`, структуру URL и хлебные крошки.
- **Не трогать `_archive/`** и `_proto-D-motion.html` — это история и прототип.
- **Боевых страниц 22** (все `index.html` в корне и подпапках). Любая правка
  `<head>` или `<body>`-обвязки должна попасть во все 22, иначе страницы
  разъедутся. Контроль — скриптом из Задачи 1.
- **Никаких внешних CDN.** Сайт должен полностью работать без обращений
  к сторонним доменам (аудитория в РФ, Google Fonts недоступен стабильно).
- **`prefers-reduced-motion` остаётся рабочим.** Каждая новая анимация
  обязана попадать под существующий блок отключения в конце `site.css`.
- **Кэш-бастер.** Сейчас `?v=20260725j`. После любой правки `assets/*`
  версия поднимается во всех 22 страницах одной командой (см. Задачу 1).
- **Русский язык — с диакритикой:** «ё» пишем как «ё», кавычки — «ёлочки».
- **В рабочей копии CRLF** (`core.autocrlf=true`, в репозитории LF). Любой
  скрипт, правящий HTML, обязан читать файл с `newline=""` и вставлять текст
  с тем же переводом строки, что уже в файле. Иначе один коммит перепишет
  все 22 файла целиком и diff станет нечитаемым. Шаблон — в Задаче 2, Шаг 5.
- **Номера строк в плане указаны на состояние до его выполнения.** После
  Задачи 2 они сдвинутся, поэтому все правки описаны ещё и по содержимому —
  ищите фрагмент, а не строку.

## Как проверяется работа

Тестового фреймворка в проекте нет и заводить его ради статического сайта
не нужно. Поэтому у каждой задачи два вида проверки, и **оба обязательны**:

1. **Машинная** — команда `grep`/`node tools/check-pages.mjs`, которая
   печатает конкретный ожидаемый результат. Если вывод не совпал — задача
   не сделана.
2. **Глазами** — открыть указанные страницы на `http://localhost:8000`
   и посмотреть названный элемент. Для задач, меняющих типографику или

## Задача 1: Скрипт контроля страниц

Без него правки в 22 файлах разъедутся молча. Делается первым, дальше
используется в каждой задаче.

**Файлы:**
- Создать: `tools/check-pages.mjs`

**Интерфейсы:**
- Отдаёт: `node tools/check-pages.mjs` → код возврата 0, если все боевые
  страницы согласованы, иначе 1 и список расхождений.
- Проверяет наличие в каждой странице: `<link rel="icon"`, `og:image`,
  `rel="preload"` для шрифта, `skip-link`, одинаковый `?v=` у css и js.

- [ ] **Шаг 1: Написать скрипт**

Создать `tools/check-pages.mjs`:

```js
/* Проверка согласованности боевых страниц In-CRM.
   Запуск: node tools/check-pages.mjs
   Падает с кодом 1, если хотя бы одна страница отличается от остальных. */
import { readFileSync } from "node:fs";
import { execSync } from "node:child_process";

// Кавычки обязательны: без них глоб раскроет шелл и в список попадут
// только файлы из корня. Файлы на `_` — превью и прототипы, они не боевые.
const pages = execSync('git ls-files "*.html"', { encoding: "utf8" })
  .trim().split(/\r?\n/)
  .filter((f) => f && !f.startsWith("_"));

// Что обязано быть на каждой боевой странице.
// Ключ — человекочитаемое имя, значение — регулярка.
const required = {
  "favicon": /<link rel="icon"[^>]*favicon\.svg/,
  "apple-touch-icon": /<link rel="apple-touch-icon"/,
  "og:image": /<meta property="og:image" content="[^"]+"/,
  "twitter:card": /<meta name="twitter:card"/,
  "preload шрифта": /<link rel="preload"[^>]*onest-cyrillic[^>]*as="font"/,
  "skip-link": /class="skip-link"/,
};

const versions = new Set();
const problems = [];

for (const page of pages) {
  const html = readFileSync(page, "utf8");

  for (const [name, re] of Object.entries(required)) {
    if (!re.test(html)) problems.push(`${page}: нет «${name}»`);
  }

  // Версия кэш-бастера должна быть одна на весь сайт
  for (const m of html.matchAll(/assets\/site\.(?:css|js)\?v=([\w.-]+)/g)) {
    versions.add(m[1]);
  }
  if (/assets\/site\.(?:css|js)"/.test(html)) {
    problems.push(`${page}: подключение assets без ?v= — кэш не сбросится`);
  }
}

if (versions.size > 1) {
  problems.push(`Разные версии кэш-бастера: ${[...versions].join(", ")}`);
}

console.log(`Проверено страниц: ${pages.length}`);
if (problems.length) {
  console.log(`\nПроблем: ${problems.length}\n` + problems.join("\n"));
  process.exit(1);
}
console.log(`Версия ассетов: ${[...versions][0]}\nВсё согласовано.`);
```

Кириллический Onest грузится на первом экране всегда — его и предзагружаем.

**Это эталонный шаблон для всех массовых правок HTML в плане** — он сохраняет

```bash
cd "c:/Users/user/Desktop/claude/интегратор" && \
git ls-files '*.html' | grep -v '^_' | while read -r f; do
  python - "$f" <<'PY'
import sys, io
path = sys.argv[1]
# newline="" — читаем и пишем байт-в-байт, не трогая CRLF
html = io.open(path, encoding="utf-8", newline="").read()
nl = "\r\n" if "\r\n" in html else "\n"

if "onest-cyrillic" in html:
    sys.exit(0)

tag = ('<link rel="preload" href="/assets/fonts/onest-cyrillic.woff2" '
       'as="font" type="font/woff2" crossorigin>' + nl)
html = html.replace('<link rel="stylesheet"', tag + '<link rel="stylesheet"', 1)

io.open(path, "w", encoding="utf-8", newline="").write(html)
PY
done
```

## Задача 3: Айдентика в выдаче — favicon, og:image, twitter-карточка

## Задача 11: Моушн-слой

Сейчас скролл-привязка есть ровно в одном месте — герой главной. На остальных
21 странице единственное движение это `[data-rise]`: один и тот же
`translateY(22px)` + fade примерно для двухсот элементов. Каждая секция входит
в кадр одинаково, и глаз перестаёт это замечать после второго экрана. Плюс
переход между страницами — белая вспышка перезагрузки, которая обесценивает
всю анимацию внутри страницы.

Задача идёт последней: она настраивается поверх уже установленного шрифта
и уже перекроенных секций (Задачи 2, 8, 9). Делать её раньше — значит
настраивать движение для разметки, которая ещё поменяется.

**Файлы:**
- Изменить: `assets/site.css` — новый блок `/* --- Моушн-слой --- */` перед `/* --- Адаптив --- */`
- Изменить: `assets/site.js` — один новый блок (спотлайт), остальное чистый CSS
- Изменить: все 23 страницы — значения `data-rise` и класс `.spot`

**Интерфейсы:**
- Потребляет: механику `[data-rise]` из `site.js:28-43`. **JS менять не нужно** —
  он ищет элементы по `querySelectorAll("[data-rise]")`, а это селектор наличия
  атрибута: `data-rise="mask"` он поймает так же, как пустой `data-rise`.
- Отдаёт: четыре именованных приёма появления `mask` / `scale` / `slide` / `fade`
  и класс `.spot` для карточек, реагирующих на курсор.

- [ ] **Шаг 1: Переходы между страницами**

Убирает вспышку перезагрузки при клике по любой внутренней ссылке.
Шапка и подвал остаются на месте, меняется только содержимое.

В `assets/site.css` перед секцией `/* --- Адаптив --- */` вставить:

```css
/* ==========================================================================
   МОУШН-СЛОЙ
   ========================================================================== */

/* --- Переход между страницами (View Transitions, MPA) --------------------- */
@view-transition{navigation:auto}
.site-header{view-transition-name:site-header}
.site-footer{view-transition-name:site-footer}
::view-transition-old(root){animation:vt-out .2s cubic-bezier(.4,0,1,1) both}
::view-transition-new(root){animation:vt-in .3s cubic-bezier(0,0,.2,1) both}
@keyframes vt-out{to{opacity:0;transform:translateY(-8px)}}
@keyframes vt-in{from{opacity:0;transform:translateY(12px)}}
```

Работает в Chrome/Edge 126+ и Safari 18+. Где не поддерживается — переход
остаётся обычным, ничего не ломается.

- [ ] **Шаг 3: Четыре приёма появления вместо одного**

Дописать в блок моушн-слоя:

```css
/* --- Приёмы появления ------------------------------------------------------ */
/* Базовый (без значения) остаётся как был — см. секцию «Появление при скролле» */

/* Заголовок секции — проявляется маской снизу вверх */
[data-rise="mask"]{opacity:1;transform:none;clip-path:inset(0 0 105% 0);
  transition:clip-path .75s cubic-bezier(.2,.7,.2,1)}

/* Карточка — подъём с лёгким уменьшением */
[data-rise="scale"]{opacity:0;transform:translateY(18px) scale(.965);
  transition:opacity .6s cubic-bezier(.2,.7,.2,1),transform .6s cubic-bezier(.2,.7,.2,1)}
[data-rise="scale"].in{opacity:1;transform:none}

/* Строка кейса — въезд сбоку, поперёк общего вертикального движения */
[data-rise="slide"]{opacity:0;transform:translateX(-26px);
  transition:opacity .6s cubic-bezier(.2,.7,.2,1),transform .7s cubic-bezier(.2,.7,.2,1)}
[data-rise="slide"].in{opacity:1;transform:none}

/* Цифра — только проявление: сдвиг мешал бы работе счётчика */
```

- [ ] **Шаг 4: Расставить приёмы по разметке**

```bash
cd "c:/Users/user/Desktop/claude/интегратор" && \
git ls-files '*.html' | grep -v '^_' | while read -r f; do
  python - "$f" <<'PY'
import sys, io, re
path = sys.argv[1]
html = io.open(path, encoding="utf-8", newline="").read()

def choose(tag):
    """Какой приём появления подходит этому тегу — по его классам."""
    m = re.search(r'class="([^"]*)"', tag)
    cls = m.group(1) if m else ""
    # Порядок важен: stat-card содержит подстроку "card"
    if "stat-card" in cls:   return "fade"
    if "section-head" in cls: return "mask"
    if "case-row" in cls:    return "slide"
    if "card" in cls or "price" in cls or "step" in cls: return "scale"
    return None

def patch(m):
    tag = m.group(0)
    if re.search(r'data-rise="', tag):   # уже размечен — не трогаем
        return tag
    kind = choose(tag)
    if not kind:
        return tag
    return tag.replace("data-rise", 'data-rise="%s"' % kind, 1)

html = re.sub(r'<[a-z]+[^>]*\bdata-rise\b[^>]*>', patch, html)
io.open(path, "w", encoding="utf-8", newline="").write(html)
PY
done
```

- [ ] **Шаг 8: Спотлайт-бордер на карточках**

Граница карточки подсвечивается под курсором. Оживляет все карточные сетки,
которых на сайте пять.

Отдельный класс `.spot`, а не `.card` напрямую: `.price--featured::before`
уже занят бейджем «ХИТ», а `.step::before` и `.step::after` заняты линией
таймлайна в мобильном медиа-блоке. Поэтому используем **`::after`** и вешаем
класс только туда, где он свободен.

```css
/* --- Спотлайт под курсором -------------------------------------------------- */
.spot{position:relative}
.spot::after{content:"";position:absolute;inset:0;border-radius:inherit;padding:1px;
  pointer-events:none;opacity:0;transition:opacity .25s ease;
  background:radial-gradient(160px circle at var(--mx,50%) var(--my,50%),
    var(--accent),transparent 70%);
  -webkit-mask:linear-gradient(#000 0 0) content-box,linear-gradient(#000 0 0);
  -webkit-mask-composite:xor;
  mask:linear-gradient(#000 0 0) content-box,linear-gradient(#000 0 0);
  mask-composite:exclude}
@media (hover:hover){ .spot:hover::after{opacity:.6} }
```

В `assets/site.js` дописать перед блоком `/* СЦЕНА ГЛАВНОЙ */`:

```js
  /* --- Спотлайт-бордер под курсором ----------------------------------------- */
  /* Один слушатель на документ вместо слушателя на каждой карточке. */
  if (!reduce && window.matchMedia("(hover:hover)").matches) {
    document.addEventListener("pointermove", function (e) {
      var host = e.target.closest && e.target.closest(".spot");
      if (!host) return;
      var r = host.getBoundingClientRect();
      host.style.setProperty("--mx", ((e.clientX - r.left) / r.width * 100) + "%");
      host.style.setProperty("--my", ((e.clientY - r.top) / r.height * 100) + "%");
    }, { passive: true });
  }
```
